## Overview

A production-ready **React.js web application** deployed on **AWS EC2** using **Nginx** for hosting.
This project demonstrates practical experience with **frontend deployment**, **server configuration**, and **cloud hosting**.

---

## Tech Stack

* **Frontend:** React.js
* **Server:** Nginx (Ubuntu 22.04)
* **Cloud:** AWS EC2
* **Tools:** Node.js, npm, Git

---

## Key Learnings

* Deployed a React build on a live EC2 instance
* Configured Nginx for static hosting and React routing
* Managed Linux server setup and AWS security groups
* Resolved common deployment issues (403, 404, routing errors)
* Improved understanding of deployment workflows and cloud environments

---

## Result

* React app successfully hosted on AWS EC2
* Stable and optimized performance
* Strengthened DevOps and deployment skills
